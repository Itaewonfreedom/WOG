# WOG 레인저 찬바라 — 전투 시스템 설계서

> 고스트 오브 쓰시마의 **흐르는 칼싸움과 피니쉬**, 귀무자의 **튕기기(弾き)·흘리기(流し)·일섬(一閃)** 을
> 숏소드(오른팔) + 초소형 버클러(왼팔) + 활을 든 **레인저** 한 명에게 녹인 전투 시스템.

- 코드: `src/core/` (엔진 독립 순수 TypeScript 시뮬레이션) · `src/render/` (Three.js 표현) · `src/ui/` · `src/audio/`
- 모든 수치는 `src/core/tuning.ts`, 기술 데이터는 `src/core/moves.ts`, 적 데이터는 `src/core/archetypes.ts` 에 있다.
- 시간 단위는 **틱(1/60초)**. 아래 표의 숫자도 모두 틱.

---

## 1. 디자인 기둥

| 기둥 | 의미 | 구현 |
|---|---|---|
| **두 개의 칼끝** | 베기와 찌르기는 서로 다른 무기다. 적마다 통하는 쪽이 다르다. | 버튼 분리 + 적 상성 규칙(§5) |
| **받아내는 칼** | 막기는 버티기, 튕기기는 기회, 흘리기는 역전, 일섬은 결착. | 방어 우선순위 파이프라인(§4) |
| **끊기지 않는 흐름** | 연격·캔슬·소프트 타깃 돌진·연쇄 피니쉬로 한 번의 교전이 한 동작처럼 이어진다. | 입력 버퍼, 캔슬 창, 진입 포즈에서 이어지는 애니메이션 |
| **끝맺음** | 무너진 적은 반드시 "마무리"된다. 마무리는 연출이자 보상이자 위협이다. | 피니쉬 6종, 위압(겁먹음), 결의 보상 |
| **거리의 선택** | 레인저는 칼과 활 사이를 자유롭게 오간다. | 캔슬 가능한 조준·속사, 회피 조준 슬로우 |

## 2. 조작

| 동작 | 키보드·마우스 | 게임패드 |
|---|---|---|
| 이동 / 카메라 | WASD / 마우스·방향키 | L스틱 / R스틱 |
| **베기** (길게 누르면 강베기) | 좌클릭 · J | □ / X |
| **찌르기** (길게 누르면 강찌르기) | 우클릭 · K | △ / Y |
| **방패** — 막기 / 타이밍 = 튕기기 | Shift · L | L1 / LB |
| **흘리기** | 방패 누른 채 Space (타이밍) | L1 + ○ |
| 방패 치기 | 방패 누른 채 베기 | L1 + □ |
| 회피 / 구르기(두 번) | Space | ○ / B |
| 활 조준 · 당기기/발사 | Q 누른 채 · 좌클릭 누르고 떼기 | L2 · R2 |
| 집중 조준(슬로우) | 조준 중 Shift | 조준 중 L1 / L3 |
| 속사 · 화살 종류 | E · 1/2/3 · 휠 | R1 · 십자키 → |
| 질풍참(결의 2) · 회복(결의 1) | F 또는 베기+찌르기 동시 · R | 십자키 ↑ · ↓ |
| 대치 · 락온 · 일시정지 | T · Tab · Esc | × · R3 · Start |

**터치(휴대폰·태블릿)**: 화면 왼쪽을 누른 곳에 가상 스틱이 생기고, 오른쪽을 끌면 카메라가 돈다. 斬(베기)·突(찌르기)·盾(방패)·避(회피)·弓(조준 토글) 버튼과 상단의 속사·질풍·회복·대치·락온·화살 버튼. 방패를 누른 채 避 = 흘리기.

**입력 버퍼**: 모든 버튼 입력은 10틱 동안 기억된다. 후딜 중에 누른 다음 공격은 합법적인 첫 틱에 즉시 나간다.

## 3. 공격 시스템

### 3.1 연격 트리 — 매 단계마다 베기/찌르기로 분기

```
베기 ─ 역베기 ─ 베기 → 가사베기 ─ 베기 → 횡베기 ─ 베기 → 회전베기(마무리)
          │               │                  └ 찌르기 → 관통 찌르기(마무리)
          │               └ 찌르기 → 관통 찌르기(마무리)
          └ 찌르기 → 되돌려 찌르기 ─ 베기 → 횡베기 / 찌르기 → 연속 찌르기

찌르기 ─ 찌르기 ─ 찌르기 → 연속 찌르기 ─ 찌르기 → 관통 찌르기(마무리)
            │                    └ 베기 → 횡베기 → …
            └ 베기 → 뽑아베기 ─ 베기 → 가사베기 / 찌르기 → 연속 찌르기
```

- 베기 계열은 **넓은 부채꼴**(다수 타격, 회피하는 적을 잡음), 찌르기 계열은 **길고 좁은 직선**(틈을 꿰뚫음, 사거리 우위).
- 두 계열을 섞어도 연격이 끊기지 않는다. 적 구성에 맞춰 한 연격 안에서 무기를 바꾸는 것이 핵심 스킬.
- **소프트 타깃**: 공격 순간 스틱 방향(없으면 정면)의 최적 적을 골라 몸을 돌리고, 간격만큼 **돌진(lunge)** 한다. 락온 중이면 락온 대상 우선.

### 3.2 강공격 (홀드) — 입력 지연 없는 차지

탭은 **즉시** 가벼운 공격이 나간다. 버튼을 계속 누르고 있으면 그 공격의 판정이 끝난 뒤 곧바로 차지 자세로 이어진다
(`chargeCheck` = 판정 종료 +4틱). 최소 16틱, 최대 40틱 차지 후 놓으면:

- **강베기(唐竹割)** / **강찌르기(破突)**: 가드 스탠스를 **깨뜨림**(heavy), 체간 42/46, 차지량에 따라 최대 ×1.3.

### 3.3 방패 치기 (방패 + 베기)

발동 5틱의 초고속 버클러 타격. 피해는 거의 없지만 **적의 예비동작을 끊고**(interrupt, 슈퍼아머 무시),
**방패 무사의 방패를 걷어낸다**(150틱 동안 베기도 통함). 이후 가사베기/연속 찌르기로 이어진다.

### 3.4 질풍참 (결의 2) — 베기+찌르기 동시 입력 또는 F

주변 최대 3명에게 순서대로 순간이동하듯 파고들어 **방어 규칙을 무시하는(trueStrike)** 체간 70 공격. 대부분의 적이 즉시 무너진다 → 연쇄 피니쉬로 연결.

### 3.5 캔슬 규칙

| 상태 | 캔슬 가능 시점 | 무엇으로 |
|---|---|---|
| 공격 | `chainFrom`(판정 종료) | 다음 연격 / 피니쉬 / 질풍참 |
| 공격 | `cancelFrom`(판정 종료 +2) | 회피 · 방패 · 조준 · 속사 |
| 회피 | 12틱 (구르기 22틱) | 공격 · 방패 · 조준(→회피 조준 슬로우) |
| 경직(hitstun) | 10틱 | 회피(낙법) |
| 피니쉬 | 40틱 | 다음 피니쉬(연쇄) · 말미 12틱 회피 |
| 일섬 | 말미 12틱 | 피니쉬 · 회피 · 방패 |

## 4. 방어 시스템 (귀무자식)

### 4.1 적 공격 등급 — 섬광 텔레그래프

| 등급 | 표시 | 막기 | 튕기기 | 흘리기 | 회피 | 일섬 |
|---|---|---|---|---|---|---|
| 일반 | 없음 | ✅ | ✅ | ✅ | ✅ | ✅ |
| **파랑** | 무기에 푸른 별빛 + 높은 "팅" | ❌ (방패가 밀려 피격) | ✅ | ✅ | ✅ | ✅ |
| **빨강** | 붉은 섬광 + 낮은 경고음 | ❌ | ❌ | ✅ | ✅ | ✅ |

섬광은 타격 `glintLead`(20틱) 전에 뜬다.

### 4.2 판정 파이프라인 — 적의 칼이 닿는 틱에 순서대로 검사

1. **무적** — 회피 무적(2~11틱) / 구르기(2~18틱) / 피니쉬 / 일섬 / 흘리기 / 질풍참 중이면 빗나감.
   무적 시작 6틱 안에 공격이 나왔다면 **완벽 회피(見切り)**: 0.35배 슬로우 0.4초 + 다음 공격 체간 ×1.6·피해 ×1.25.
   (뒤로 회피해 사거리 밖으로 벗어났어도, 그 공격이 회피 시작 위치에 닿았을 거리라면 완벽 회피로 인정)
2. **일섬(一閃)** — 공격 버튼을 적의 타격 **5틱 이내 직전**에 눌러 공격 예비동작이 막 시작됐다면 성립.
   - 적의 공격은 무효, 레인저가 적을 **베고 지나가며** 적은 한 박자 멈췄다가 쓰러진다(즉사, 보스는 최대 체력 18%).
   - **매싱 방지**: 직전 18틱 안에 다른 공격 입력이 있었다면 일섬 불가. "침착한 단 한 번"만 인정.
   - **연쇄 일섬(連鎖一閃)**: 일섬 후 110틱 안에 다음 일섬 시 판정이 8틱으로 넓어지고, 매싱 제한이 풀리며, 체인 카운트가 오른다.
   - 판정 창은 레인저 공격의 발동 시간에 잘리지 않는다(공격 판정이 끝나기 전까지 유효).
3. **흘리기(流し)** — 방패를 든 채 회피를 누르면 11틱짜리 "흘리기 자세"가 된다. 그 사이 적의 칼이 닿으면:
   - 레인저는 스틱 방향(기본 오른쪽) 옆으로 미끄러지고, 적은 헛친 기세로 1.7m **앞으로 고꾸라진다(overextended, 70틱)** — 등이 열린다.
   - **빨간 공격도 흘릴 수 있는 유일한 방어.**
   - 이어서 공격 → **흘려베기** 피니쉬(즉사).
   - 타이밍을 놓치면 그냥 방패 옆걸음(경직 22틱) — 맞을 수 있다.
4. **튕기기(弾き)** — 방패를 **새로 눌러** 올린 뒤 8틱 안에 정면(±70°)으로 온 일반/파랑 공격.
   - 적의 칼이 튕겨나 **반동 42틱** + 체간 26 (보스 ×0.8). 체간이 가득 차면 즉시 체간 붕괴.
   - 튕긴 직후 **14틱 안에 공격 → 튕기기 일섬(弾き一閃)**: 즉사 카운터(보스는 큰 피해).
   - 40틱 안의 일반 반격은 체간 ×2.
   - 방패는 **탭해도** 튕기기 창(8틱) 동안은 올라가 있다. 경직·히트스톱 중에 누른 입력도 버퍼에 남아 튕기기로 인정된다.
   - 튕기기 자세 중 방패를 다시 누르면 두 번째 적의 공격도 연속으로 튕길 수 있다(성공 직후의 재입력은 스팸으로 치지 않는다).
   - **스팸 페널티**: 직전 방패 입력과 22틱 이내면 판정이 3틱으로 줄어든다. 방패를 계속 들고만 있으면 튕기기가 아닌 막기.
   - 날아오는 **화살·쿠나이도 튕길 수 있다.**
5. **막기** — 정면 일반 공격을 체간(기세)으로 받는다. 기세가 가득 차면 **방패가 밀려(guard break) 55틱 경직.**
   초소형 버클러라 **정면 ±70°만** 막는다 — 등 뒤와 옆은 무방비.
6. **피격**

### 4.3 설계 의도

- 막기 → 튕기기 → 흘리기 → 일섬 순으로 **위험도와 보상이 함께 오른다.**
- 파랑은 "튕기기 실력 체크", 빨강은 "흘리기/회피 판단 체크".
- 일섬은 공격 버튼으로 하는 방어 — 공격적인 플레이어에게 최고의 보상, 하지만 너무 이르면 그대로 맞는다.

## 5. 적 상성 — 베기와 찌르기

| 적 | 베기 | 찌르기 | 방패 치기 | 화살 | 전술 포인트 |
|---|---|---|---|---|---|
| **낭인 검사** 浪人 | ○ 보통 | ○ 보통 | ○ | ○ 헤드샷 즉사 | 가드를 올린다 → 강공격/방패 치기로 깨라. 파랑 돌진 찌르기, 허초. |
| **방패 무사** 盾持 | ✕ **정면이면 튕겨남**(피해 0, 플레이어 반동) | ◎ **방패 틈새** 피해 ×1.25, 체간 ×2 | ◎ **방패를 걷어냄** | 정면은 박힘 · **관통 화살은 방패를 걷어냄** | 옆·뒤에서는 베기도 통한다. |
| **창병** 槍足軽 | ◎ **창대를 쳐냄** 피해 ×1.2, 체간 ×2 | ✕ **정면이면 창대에 막힘**(피해 25%, 밀려남) | ○ | ○ | 긴 리치 찌르기, 빨강 휩쓸기 → 흘리기. |
| **갑주 무사** 鎧武者 | △ **미끄러짐** 피해 ×0.25, 체간 ×0.45, 경직 없음 | ◎ **갑옷 틈새** 피해·체간 ×1.6 | △ | 몸통 튕김(관통 화살은 통과), 머리 ×1.2 | 슈퍼아머. 빨강 투구 깨기. |
| **쌍검 시노비** 双刃 | ◎ **넓은 궤적** 피해 ×1.4, 체간 ×1.5 | ✕ **몸을 틀어 회피** 후 즉시 반격 | ○ | ○ | 단, **공격 중·경직 중에는 회피 못 함** → 연격 끝을 찔러라. |
| **궁수** 弓兵 | ○ | ○ | ○ | 헤드샷 1발 | 원거리 토큰으로 한 명씩 사격. 붙으면 단도. |
| **철갑 대장** 影虎 | 1막 △ / **2막 ◎** | **1막 ◎** / 2막 △ | △/○ | 1막 몸통 튕김 | 체력 55% 이하에서 **갑옷 파쇄** → 상성이 뒤집힌다. |

**방향 규칙**: 방패 튕김·창대 막힘은 **정면 ±75°** 에서만. 뒤·옆은 보통 판정.
**무방비 규칙**: 적이 체간 붕괴·반동·고꾸라짐·가드 붕괴·겁먹음·비틀거림 중이면 튕김·창대·회피는 발동하지 않는다(갑옷 미끄러짐은 유지).
**HUD**: 적 머리 위에 `약점 斬 베기` / `약점 突 찌르기` 태그. 잘못 치면 `튕겨남 — 방패엔 찌르기` 같은 교정 문구가 뜬다.

## 6. 체간 · 피니쉬

### 6.1 체간(posture)

- 공격이 쌓는 체간 = 기술 체간 × 상성 배율 × (반격/회피반격/겁먹음 보너스) × 차지 배율.
- 가득 차면 **체간 붕괴(broken, 170틱)** — 무릎을 꿇고 칼끝이 땅에 닿는다. 붉게 맥동하며 `피니쉬` 프롬프트가 뜬다.
- 100틱 동안 체간 피해가 없으면 서서히 회복. 붕괴에서 회복하면 체간 40%에서 재개.
- 체력 20% 이하에서 비틀거리는(경직·가드 붕괴·겁먹음) 일반 적도 피니쉬 가능.

### 6.2 피니쉬 6종

| 피니쉬 | 조건 | 연출 | 결과 |
|---|---|---|---|
| **일도양단** 一刀両断 | 무너진 적 + **베기** | 돌진 → 머리 위로 치켜든 뒤 대각으로 내리긋기 → 잔심 → 피 털기(血振り) | 즉사(보스 22%) |
| **심장 관통** 心突 | 무너진 적 + **찌르기** | 돌진 → 버클러로 버티며 깊이 찌르기 → 비틀기 → 방패로 밀쳐 뽑기 | 즉사(보스 22%) |
| **흘려베기** 流し斬り | 흘리기 후 등 돌린 적 + 공격 | 등 뒤 대각 베기 | 즉사 |
| **일섬** 一閃 | 타격 직전 공격 | 스쳐 지나간 뒤 적이 멈췄다 쓰러짐, 화면 섬광 | 즉사(보스 18%) |
| **튕기기 일섬** 弾き一閃 | 튕기기 직후 14틱 안 공격 | 〃 | 즉사 |
| **대치 참** 対峙斬り | 대치 성공 | 〃 | 즉사 |

- **약점 마무리**: 적의 약점과 같은 버튼으로 피니쉬하면 결의 +0.25 추가, 보스 피해 ×1.2, 위압 확률 +25%.
- **연쇄 피니쉬(連殺)**: 피니쉬 40틱 이후 다른 무너진 적(7m 이내)이 있으면 공격 입력만으로 끊김 없이 다음 피니쉬.
- **위압(怯え)**: 피니쉬 순간 9m 안의 적은 `35% × (1 − 용기×0.6)` 확률로 겁먹고 물러난다(110틱, 받는 체간 ×1.5). 보스는 면역.
- 피니쉬·일섬 동안 레인저는 무적이고, AI는 공격을 시작하지 않는다(시네마틱 존중).

## 7. 활쏘기

### 7.1 당기기 모델

```
당김량 0 ─────────▶ 1 (만작) ─ 정사 창 18틱 ─▶ 피로(떨림) 120틱에 걸쳐 증가
```

| 화살 | 만작 틱 | 기본 피해 | 속도 | 특수 | 최대 |
|---|---|---|---|---|---|
| 일반 矢 | 34 | 22 | 20→62 m/s | — | 24 |
| 관통 貫 | 52 | 34 | ×0.8, 낙차 큼 | 갑옷 관통, **방패 걷어냄** | 6 |
| 화전 火 | 40 | 14 | — | 화상 150틱(지속 피해) + 공황 | 4 |

- 피해 = 기본 × (0.35 + 0.65 × 당김량) × (정사 ×1.3). 정사(正射: 만작 직후 창 안에서 놓기)는 **탄퍼짐 0**.
- 덜 당기면 느리고 약하고 퍼진다. 오래 버티면 팔이 떨려(레티클이 붉게 흔들림) 퍼짐이 다시 커진다.
- **헤드샷 ×2.6** — 정사 일반 화살 헤드샷(22×1.3×2.6≈74)은 낭인(60)을 한 발에 쓰러뜨린다.
- 탄도: 중력 적용 + 레티클 지점으로 발사각을 보정한다. 움직이는 적은 **리드**가 필요하다(관통 화살은 특히).
- 적 피격 시 경직(슈퍼아머 제외) → 궁수의 사격, 적의 예비동작을 끊을 수 있다.

### 7.2 레인저의 보조 사격

- **속사(E / R1)**: 조준 없이 가장 적절한 적의 가슴으로 즉시 한 발(20틱, 피해 11). 연격 후딜에서 캔슬해 궁수를 끊는 용도.
- **집중 조준**: 조준 중 Shift/L1 → 시간 0.3배, 결의를 초당 0.5 소모.
- **회피 조준**: 회피 직후(20틱 안) 조준하면 결의 소모 없이 1.1초간 0.4배 슬로우.
- 쓰러진 적에게서 화살 1개 회수, 막을 넘으면 보급.

## 8. 대치 (対峙, Standoff)

1. 막이 시작되고 적이 걸어 들어오는 동안(약 5.5초) `T/×` 로 대치를 건다.
2. 가장 가까운 근접 적이 6.5m 앞에 선다. 카메라는 두 사람을 옆에서 잡는 **와이드 프로필 샷**, 레터박스.
3. **베기 버튼을 누른 채** 기다린다. 우두머리는 0~2회 **허초(움찔)** 로 속인다 — 이때 떼면 실패.
4. 진짜로 달려드는 순간(도착 전 14틱 창) **떼면** 일격(대치 참).
5. **연쇄**: 다음 적이 달려들면 베기를 **눌러** 이어 벤다. 최대 3명.
6. 실패하면 달려든 칼에 체력 30 피해 후 전투 개시.

## 9. 적 AI

- **공격 토큰 디렉터**: 동시에 공격할 수 있는 근접 적은 최대 **2명**(보스전은 보스만). 공격 중인 적은 토큰을 반납해도 "공격 중"으로 계산된다. 나머지는 선호 거리 +1.6~3m 링에서 **포위·선회**하고 서로 간격을 벌린다.
- **원거리 토큰**: 동시에 활을 당기는 궁수는 1명. 가까워지면 물러나고, 2m 안이면 단도.
- **연계**: 연참 계열은 콤보 확률로 이어 치고, 허초는 진짜 공격으로 이어진다.
- **반응**: 맞으면 확률적으로 가드 스탠스(50~100틱). 플레이어가 코앞에서 예비동작을 하면 반사적으로 가드. 튕겨내거나(방패 무사), 회피하면(시노비) **즉시 반격** 플래그.
- **추적**: 각 공격은 `trackUntil` 틱까지만 플레이어를 향해 몸을 돌린다 → 그 뒤 옆으로 피하면 헛친다(공정한 회피).
- 피니쉬·일섬·질풍참 동안에는 새 공격을 시작하지 않는다.

### 9.1 포이즈 — 연타 스턴락 방지와 적의 역튕기기

적은 짧은 간격(90틱)으로 연속해서 맞은 횟수를 센다. 한계(`ai.poise`)에 도달하면 경직을 짧게 끊고 **돌파(breakout)** 한다.

| 적 | 한계 | 돌파 방식 |
|---|---|---|
| 낭인 검사 | 3 | **튕기기 자세(역튕기기)** — 50틱 동안 가벼운 공격을 튕겨낸다. 플레이어는 30틱 반동 후(12틱부터 방패·회피로 복구 가능) 반격을 받는다. |
| 철갑 대장 | 2 | 튕기기 자세 + 플레이어가 예비동작을 보이면 확률적으로 즉시 튕기기 자세 |
| 창병 · 쌍검 시노비 · 궁수 | 2 · 2 · 3 | 뒤로 물러나며(2.2m) 즉시 반격 |
| 방패 무사 | 2 | 방패 돌격(파랑) 반격 |
| 갑주 무사 | — | 원래 가벼운 공격에 경직되지 않는다(슈퍼아머) |

튕기기 자세는 **강공격(홀드)·방패 치기·질풍참**으로만 깨진다 → 연타만으로는 이길 수 없고, 버튼 선택(가벼운/무거운, 베기/찌르기)이 계속 의미를 갖는다.
귀무자의 튕기기는 양방향이다: 플레이어가 적을 튕기듯, 적도 플레이어를 튕긴다.

### 15.2 애니메이션 파이프라인 (표현 계층)

- **공통 타임라인** (`core/timeline.ts`): 기술마다 `windupEnd → release → contact(=첫 active 틱) → followEnd`,
  피니쉬·일섬·질풍참마다 `contact / pull / victimFall / victimDown / trail` 을 한 곳에서 정의한다.
  코어의 피해·히트스톱·피니쉬 impact, 휘두름 소리(release), 포즈의 타격 키, 트레일 구간, 피해자 반응이 모두 이 값을 쓴다.
  release 는 startup 안에서 계산하므로 입력 반응성과 방어 판정 창은 바뀌지 않는다.
- **진입 포즈 연결**: 모든 동작은 시작 순간의 실제 포즈(이전 기술의 종료 자세, 캔슬, 차지)에서 출발하고, 손의 속도를 다음 windup 으로 이어받는다.
  골반·다리 → 몸통 → 팔·무기 순서로 시간차(`lerpPoseParts`)를 두고, 베기는 가슴을 축으로 한 호, 찌르기는 직선 + 가속 곡선으로 움직인다.
- **발 접지** (`render/feet.ts`): 지지발은 월드 좌표에 고정되고 움직이는 발만 들어 예측 위치에 착지한다. 걷기·달리기는 보폭 주기(위상)로 좌우 발이 번갈아 딛고,
  출발·방향 전환처럼 딛는 발이 들어야 할 지점보다 한참 뒤에 남으면 주기를 그 발에 다시 맞춘다. 착지 직전에는 목표를 고정해 땅에 닿은 발이 끌리지 않는다.
  활을 겨눈 채 움직이면 무릎을 굽혀 골반 높이를 유지해 활 든 손이 흔들리지 않는다. 골반 낮춤은 딛는 발이 착지할 때까지 필요한 만큼 미리 내려가 착지 순간에 튀지 않는다.
  일섬·질풍참 같은 초고속 돌진에서는 발이 몸과 함께 떠서 지나가고, 쓰러지는 몸의 발은 땅 아래로 들어가지 않는다. 공격 돌진은 앞발이 contact 틱에 디딘다(fumikomi),
  회전베기는 앞발 피벗, 횡이동·후진·회피는 방향에 맞는 발부터 딛는다. 다리 길이를 넘으면 골반을 낮춘다. 발소리·먼지는 실제 착지 이벤트에서 난다.
  캐릭터 위치·사거리는 언제나 코어가 소유한다(렌더 보정 없음).
- **IK**: 양손 무기는 도달거리 보정 뒤에도 같은 그립을 잡고, 팔꿈치·무릎의 굽힘 평면은 시간적으로 평활화해 뒤집히지 않으며, 발은 보정된 발목에 붙어 있다.
- **시간 기준**: 렌더의 시뮬레이션 dt 는 `World.simClock`(틱 + 보간 위상)의 차이다. 히트스톱·일시정지 동안 0, 슬로모에서 느려지고, 히트스톱이 시작된 프레임까지 흐른 시간도 빠짐없이 반영된다.
  화면은 코어보다 한 틱 뒤를 보간하므로, 히트스톱이 걸리면 화면은 타격 틱에 **도달할 때까지 계속 움직인 뒤** 정확히 k 틱 동안 멈춘다(주사율과 무관하게 같은 멈춤 길이·같은 타격 자세).
  타격 소리·피·카메라 흔들림 같은 연출 이벤트는 발생 틱이 찍혀 화면 시각이 그 틱에 닿는 프레임에 재생된다(칼이 닿기 전에 피가 튀지 않는다).
  튕기기·방패 튕김·처치로 공격이 그 틱에 다른 동작으로 바뀌면, 코어가 기록한 마지막 틱(`Fighter.replaced`)까지 화면이 그 공격을 이어 그리고(트레일 포함) 멈춘 뒤 새 동작이 그 자세에서 시작한다.
  트레일은 시뮬레이션 시각이 찍힌 링 버퍼 샘플을 고정 시간 격자로 다시 그려 30/60/120Hz 에서 같은 모양이고, 새 공격이나 순간이동 사이를 잇지 않는다.
- **처치 연출**: HP 0 인 `finished` 피해자는 전투상 죽은 상태(재타격·AI·집계 없음)로 연출 타임라인만 끝까지 진행한 뒤 `dead` 가 되고, 시체는 같은 쓰러짐 궤적을 이어받는다.
  일섬 혈흔 같은 지연 효과는 피해자의 액션 타임라인에 묶여(일시정지·슬로모·재시작 안전) 발생한다.

### 15.1 Unity / Unreal 이식 가이드

| TS 모듈 | Unity | Unreal |
|---|---|---|
| `World.step` 고정 틱 | `FixedUpdate` (Time.fixedDeltaTime = 1/60), 히트스톱은 자체 카운터 | `Tick` + 누산기, 또는 Chaos Fixed Tick |
| `MoveDef` 데이터 | ScriptableObject | DataAsset / DataTable |
| `resolveOnPlayer/Enemy` | CombatResolver 정적 클래스 | UCombatSubsystem |
| `Animator`(IK 궤적) | Animation Rigging Two Bone IK + 궤적 커브, 또는 모션캡처 클립에 판정 틱을 Animation Event 로 매핑 | Control Rig + AnimNotify(판정 창) |
| `CombatEvent` | C# event / UnityEvent | Delegates / GameplayCue |

프레임 데이터(발동·판정·후딜·캔슬 틱)만 유지하면 판정 로직은 그대로 옮겨진다.

## 16. 튜닝 가이드

- **판정 너그러움**: 설정의 난이도가 `windowScale`(쉬움 1.6 / 보통 1 / 어려움 0.75)로 튕기기·흘리기·일섬·정사·대치 창을 일괄 조절한다.
- **적의 압박**: `T.maxAttackers`, 각 적의 `ai.cooldown`, `aggression`.
- **상성의 강도**: `archetypes.ts` 의 `dmgMul`/`postureMul`. 상성을 무시하고도 이길 수 있게 하려면 bounce/haft 의 `postureMul` 을 올린다.
- **타격감**: `HITSTOP` 표와 `game.ts` 의 이벤트 핸들러(흔들림·FOV 킥·파티클 수).

`node scripts/anim-capture.mjs --dist dist --out <dir> [--hz 60] [--only a,b]` 는 멈춘 시계로 빌드본을 한 프레임씩 실제 키 입력으로 구동해 시나리오별 연속 프레임과 지표를 저장한다(수정 전후 비교용).
`npm run smoke` 는 빌드본을 Playwright 로 띄워 실제 키 입력(대치, 락온, 공격, 방패, 일시정지)으로 플레이하고 페이지 오류가 없는지 확인한다.
