# WOG — 레인저 찬바라 (Ranger Chanbara)

고스트 오브 쓰시마 풍의 **흐르는 칼싸움과 피니쉬**, 귀무자 풍의 **튕기기(弾き)·흘리기(流し)·일섬(一閃)** 을
**숏소드(오른팔) + 초소형 버클러(왼팔) + 활**을 든 레인저에게 담은 3D 찬바라 전투 시스템입니다.
브라우저에서 바로 돌아가는 플레이어블 데모(Three.js)와, 엔진에 독립적인 전투 코어(TypeScript)로 구성됩니다.

**플레이:** https://itaewonfreedom.github.io/WOG/ (GitHub Pages — `gh-pages` 브랜치, 푸시할 때마다 자동 배포)

```bash
npm install
npm run dev          # http://localhost:5173 에서 플레이
npm test             # 전투 규칙 단위 테스트 (Vitest)
npm run build        # 정적 빌드 → dist/
npm run build:single # 단일 HTML 파일 → dist-single/index.html (공유용)
npm run smoke        # 실제 키 입력으로 브라우저 스모크 테스트 (Playwright)
```

키보드·마우스, 게임패드(표준 매핑), 휴대폰·태블릿 터치(가상 스틱 + 斬/突/盾/避/弓 버튼)를 모두 지원합니다.

## 핵심 시스템

| 시스템 | 요약 |
|---|---|
| **베기 / 찌르기 분리** | 두 버튼, 두 연격 트리. 매 단계에서 서로 분기(역베기→되돌려 찌르기, 찌르기→뽑아베기 …). 길게 누르면 가드를 부수는 강베기/강찌르기(탭은 입력 지연 0). |
| **적 상성** | 방패 무사·갑주 무사는 **찌르기**, 창병·쌍검 시노비는 **베기**. 잘못 치면 방패에 튕겨나고, 창대에 막히고, 갑옷에 미끄러지고, 몸을 틀어 피한다. 방향(정면/측후면)도 따진다. 보스는 갑옷이 깨지면 상성이 뒤집힌다. |
| **튕기기** | 타격 직전 8틱 안에 버클러를 올리면 적의 칼이 튕겨나고 체간이 깎인다. 곧바로 공격하면 **튕기기 일섬**(즉사 카운터). 파랑 섬광 공격은 튕기기로만 받을 수 있다. 화살도 튕긴다. |
| **흘리기** | 방패 + 회피 타이밍. **빨간 섬광(막기·튕기기 불가) 공격까지** 흘려내고, 앞으로 고꾸라진 적의 등을 **흘려베기**. |
| **일섬** | 적의 타격 직전 단 한 번의 공격 = 즉사. 연타하면 나가지 않는다. 이어서 성공하면 **연쇄 일섬**. |
| **체간 → 피니쉬** | 체간이 무너진 적에게 베기 = **일도양단**, 찌르기 = **심장 관통**. 약점 버튼으로 마무리하면 보너스, 무너진 적이 여럿이면 **연쇄 피니쉬**, 주변 적은 겁먹는다. |
| **활쏘기** | 당김량·**만작(정사) 창**·피로 떨림·탄도·헤드샷. 일반/관통/화전 화살, 속사, 집중 조준 슬로우, 회피 직후 조준 슬로우. |
| **대치** | 적이 다가올 때 대치를 걸고, 허초에 속지 않고 달려드는 순간 베기를 떼면 일격. 최대 3연쇄. |
| **AI** | 공격 토큰(동시 공격 2명), 포위 선회, 섬광 텔레그래프, 허초, 가드/회피 반응, 궁수 사격 토큰. |
| **연출** | 히트스톱, 슬로모, 피니쉬/일섬/대치 시네마틱 카메라, 무기 궤적 트레일, 절차적 사운드(무음원 WebAudio), 골든아워 억새 들판, 흑백 영화 모드. |

자세한 규칙·프레임 데이터·튜닝·엔진 이식 가이드는 **[docs/COMBAT_DESIGN.md](docs/COMBAT_DESIGN.md)** 에 있습니다.

## 조작

| 동작 | 키보드·마우스 | 게임패드 |
|---|---|---|
| 이동 / 카메라 | WASD / 마우스(화면 클릭 후)·방향키 | L스틱 / R스틱 |
| 베기 / 찌르기 (길게: 강공격) | 좌클릭·J / 우클릭·K | □ / △ |
| 방패(막기·튕기기) | Shift · L | L1 |
| 흘리기 | 방패 + Space | L1 + ○ |
| 방패 치기 | 방패 + 베기 | L1 + □ |
| 회피 / 구르기 | Space / 두 번 | ○ |
| 활 조준 · 당기기 | Q 누른 채 좌클릭 누르고 떼기 | L2 · R2 |
| 속사 · 화살 종류 | E · 1/2/3 | R1 · 십자키 → |
| 질풍참 · 회복 | F(베기+찌르기) · R | ↑ · ↓ |
| 대치 · 락온 · 일시정지 · 도움말 | T · Tab · Esc · H | × · R3 · Start |

## 구조

```
src/core/     엔진 독립 전투 시뮬레이션 (60Hz 고정 틱, DOM/Three.js 의존 없음)
  tuning.ts     모든 판정 창·수치
  moves.ts      기술 프레임 데이터 (플레이어 연격 트리 + 적 기술)
  archetypes.ts 적 스탯·상성·AI 성향
  combat.ts     판정 파이프라인 (일섬 > 흘리기 > 튕기기 > 막기 > 피격), 상성, 체간, 피니쉬
  player.ts     입력 해석, 연격 분기, 캔슬, 소프트 타깃
  ai.ts         공격 토큰 디렉터, 적 브레인
  bow.ts        당기기 모델, 탄도, 헤드샷, 투사체
  standoff.ts   대치 / waves.ts 캠페인 / world.ts 루프·시간 제어
src/render/   Three.js 표현 (IK 캐릭터, 무기 궤적 애니메이션, 카메라, 이펙트, 환경)
src/audio/    절차적 WebAudio 효과음
src/ui/       HUD · 메뉴
tests/        Vitest 전투 규칙 테스트
```

코어는 `CombatEvent` 스트림만 내보내고, 렌더·오디오·HUD 는 그 이벤트를 구독합니다.
Unity/Unreal 로 옮길 때는 `src/core` 를 그대로 포팅하고 프레임 데이터만 애니메이션에 맞추면 됩니다(설계서 §15).
